# ADR 0046 — Terrain and tactical movement

**Status:** Proposed — Raymond's Real-Time Architecture review required before release.
**Extends/amends:** ADR 0003 tactical state, 0013 undo, 0016 fog, 0019 checkpoints, 0024 encounters, 0025 replay, 0029 walls, 0030 portals, 0037 library boards, 0042 map changes, 0043 atomic placement and 0044 sight.

## Decision

Terrain is optional canonical table content: sparse compressed row runs for base ground plus up to 32 privately named temporary effects. Normal is implicit; erase removes only the selected layer and previews as translucent white without a Difficult symbol. Blocked wins and Difficult doubles once. Total overridden cells across layers are bounded at 10,000. Paint requests are bounded below 32 KiB and decided atomically. Runtime validation also bounds canonical content from saved JSON.

GM paint and effect commands include the current board epoch and terrain edit revision. Revisions advance on all terrain edits, undo and restores; epochs advance on map/grid geometry changes and restores, outside checkpoint content. Stale gestures and saves fail without writes. New token moves include expected origin and board epoch; legacy moves receive the same current-state validation.

Movement uses the actual committed origin, a straight segment and a swept square footprint. Blocked terrain checks use the full square with positive-area overlap; wall sweeps retain the existing 10% inset and ignore walls already intersecting the original footprint for the route only. Manual fog is concealment, never a physical movement restriction: authorized players may ordinarily move their owned, unhidden tokens into, entirely within, across thin strips between clear endpoints and out of fog, including after GM placement or newly added fog covers them. Ordinary GM movement follows the same physical validation. Ownership, hidden-token restrictions and revocation remain enforced before movement. Blocked terrain, walls, closed/locked portals and all destination checks still apply; Difficult cost remains proportional under fog. No actor-specific fog branch, client permission flag or automatic Reposition is used. A GM-only one-move Reposition bypasses route restrictions but still requires a wall- and Blocked-free destination, and is consumed by one attempt, including a refusal. Painting over tokens is legal and never displaces them; Blocked terrain has no starting escape exception and requires GM resolution. Moving never changes manual fog. Owners retain their tokens; other concealed content and private drag previews remain filtered, including hide-first/reveal-last ordering for positional edits combined with renames.

Cost is Chebyshev distance for snapped movement or Euclidean distance for free movement, multiplied by one plus the union length of Difficult-overlap intervals in route parameter space. Boundary contact has zero area and no Difficult cost. Neither the origin nor cost is rounded during calculation. TokenMoved contains positions only.

Players receive a separate effective terrain projection with temporary markers; no canonical layers, effect ids/names, prior values or edit revision. Knowledge is defined by the current map, fog and sight; a cell must be fully visible and unfogged. The same conservative coverage predicate interprets absent overrides as Normal. Changed projections produce filtered snapshots; unchanged terrain edits are redacted. Snapshots, history, replay, reconnect and ephemeral previews use current committed visibility. Ghosts are never sight origins. Fog boundaries still block sight except for regions containing the sight token's centre; range, walls/windows/doors and combined owned-token sight are unchanged. Manual fog still conceals unowned content where sight overlaps it. Refusal text is generic. Routes under fog or outside sight remain legal when physical validation and authorization permit them. Route feedback is visual: red dashed for known collisions, faint dashed while uncertain, and solid for checked clear routes; distance/cost labels contain no obstruction-status text. Plain walls remain GM-only. A separate unpersisted advisory request is capped at 10 per socket per second and returns a private status only to the requesting socket, never geometry, obstacle identity or cost. The pure viewer filter authorizes the token, checks origin/epoch and requires a player’s entire footprint route to be inside current known coverage before consulting private wall geometry. Concealed player routes return unknown with or without obstacles, including fog-only routes; full concealed cost stays unknown even when movement is permitted. GM local and server feedback accurately report physical collisions and proportional cost while ignoring fog as an obstruction. Replies are matched to the current request and committed sequence, redacted edits refresh a stationary drag, and every actual move is independently revalidated. Fog-only changes during a drag do not refuse movement; new physical restrictions still do. GM view-as-player remains read-only.

Map/image-dimension replacement resets terrain or installs the selected library base atomically in MapSet. Spacing/origin changes require explicit reset when terrain exists and use a composite GridSet replacement. Cosmetic grid/unit edits preserve cells. Undo restores exact terrain and rejects overwriting later affected values; map/grid changes close earlier terrain undo entries. Checkpoints include all layers; reusable encounter templates include base only. Legacy records mean Normal.

Library maps store only base runs in their existing board JSON. Owner-authorized preparation GET/PUT reads and compare-and-swaps grid and board atomically using a content revision token. Legacy board writes preserve omitted terrain; legacy geometry changes refuse an implicit terrain reset. Library placement resolves the saved content inside LiveRoom's FIFO. Room edits never write back. No SQL migration.

Room preparation uses the GM-only `scene.savePreparation` command. Its map/epoch/revision context and every edit are validated against the current FIFO state and a private sequential decide/reduce fold before one atomic append. A refusal or append failure publishes no prefix; the existing events share one undo action and retain their existing viewer filtering. The strict, non-recursive whitelist permits only walls, portal designation, fog replacement, sight settings and terrain paint. The envelope is strictly below 768 KiB with at most 1,600 edits; all paint chunks together affect at most 10,000 distinct cell positions, and each paint remains strictly below 32 KiB. A dedicated preparation POST authorizes the active GM and live session before parsing a body strictly below 768 KiB, then submits the same command to LiveRoom. Socket.IO and general JSON retain their 64-KiB caps. The response carries only the final sequence; the client waits for filtered ordered events to reach it before completing Save. The 32-effect and total 10,000 overridden-cell limits remain unchanged. The client sends changed values and selected-base erasures only, splitting fragmented changes into at most 256 runs per paint with consecutive internal revisions; all chunks commit or fail together.

Cosmetic/unit grid saves preserve private terrain and its original revision context. Terrain participates in the editor's unsaved-work prompt; the GM may explicitly keep the draft while entering Grid. Private terrain must be saved or explicitly discarded before a spacing/origin change. Committed terrain resets keep their existing explicit confirmation. Library placement compares the chosen geometry with the saved library grid whenever prepared base terrain exists; incompatible spacing or origin requires cancellation or an explicit `resetTerrain` choice, which installs Normal ground in the same reversible MapSet. Matching geometry and cosmetic/unit overrides still copy the exact base. No indices are remapped and library content is unchanged.

Movement knowledge traversal rejects non-safe integer ranges and ranges wider than 20,000 indices on either axis. A shared 40,000-iteration budget counts row and column work before interval skips, retaining the 20,000 visited-cell limit. Unsafe or over-budget routes return unknown without restricting otherwise authorized off-map movement. A timeout-killed subprocess regression covers committed extreme origins on both axes.

## Consequences and review

Exact whole-cell terrain is deliberately separate from geometric walls and fog. No remapping, pathfinding, budgets, automatic expiry, terrain detection or UVTT terrain transport. Conservative cell visibility can hide partly visible terrain. Review the 32-layer, 10,000-cell and 32-KiB bounds with runtime/latency evidence. Shared contracts and board files overlap unmerged feat/area-effects; reconcile explicitly when either branch merges. Refreshed branch comparison confirms overlap in commands/events/state/decide/reducer/visibility, Board.tsx, boardView.ts, RoomPage.tsx, styles.css and movement/fog integration tests. No branch was merged or rewritten. Existing proposed ADR reviews remain outstanding. Implementation and tests do not constitute owner approval.
